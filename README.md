# ProjectDox public-help accessibility example

This repository publishes one original, unbranded synthetic before/after illustration about equivalent text for informative diagrams.

It is not Avolve software, not a reproduction of ProjectDox, and not a full accessibility audit or compliance verdict. Its inspiration is a single publicly readable image alternative in the ProjectDox 9.4 help. Authenticated product pages were not accessed.

The website contains only the synthetic demo page and its original diagram.
